Timbó Hardware
Proyecto de desarrollo web estático creado como práctica de front-end.
Tecnologías utilizadas

HTML5 — Se utilizó para estructurar el contenido de la página mediante etiquetas semánticas como <header>, <nav>, <main> y <footer>.
CSS3 — Se utilizó para el diseño visual del sitio, incluyendo colores, tipografías, disposición de elementos y estilos generales de la interfaz.

Descripción
Sitio web de una tienda de hardware llamada Timbó, que cuenta con secciones dedicadas a monitores, teclados y mouses. El diseño utiliza una estética oscura con colores negro y verde neón orientada al público gamer y tecnológico.
